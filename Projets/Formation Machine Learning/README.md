# 04 — Formation Machine Learning

Formation ML **orientée data engineer** : comprendre, entraîner et évaluer des modèles avec scikit-learn,
préparer proprement les données, et faire le lien **ML ↔ data engineering / MLOps**. But : renforcer mon
profil pour la recherche d'emploi data engineer (savoir dialoguer avec les data scientists et
industrialiser leurs modèles) — pas devenir data scientist.

## Organisation
- `Programme_ML.md` — la feuille de route (phases 0 → 7).
- `cours/semaine-XX/` — les fiches de cours.
- `exercices/python/` — mes notebooks d'exercices ; `exercices/concepts/` — questionnaires écrits.
- `data/` — jeux de données d'entraînement.
- `fiches-revision/` — notes de révision.
- `CLAUDE.md` — méthode d'apprentissage (générique) + règles spécifiques ML.

## Méthode
Fiche d'abord, exercices ensuite ; un seul thème à la fois ; code en notebooks `.ipynb` commentés en
français ; mini-projet de synthèse cumulatif en fin d'étape. (Mêmes règles que le parcours data engineer.)
