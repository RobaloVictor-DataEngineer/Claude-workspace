# Formation Fabric & PySpark

Apprendre et maîtriser **PySpark** (le code) et **Microsoft Fabric** (la plateforme), en visant d'abord les **entretiens** (offre Groupe Premium), puis la pratique en poste.

## Pourquoi les deux ensemble
PySpark n'est pas un sujet « à part » : c'est le **langage/moteur Spark** que l'on écrit **dans les notebooks de Fabric** (couche Lakehouse). On apprend donc PySpark (pratiquable tout de suite) puis Fabric qui l'orchestre.

## Comment on avance
- **Méthode** : fiche d'abord, puis exercice ; un seul thème à la fois (voir `CLAUDE.md`).
- **PySpark** : exercices de **code** en notebook (`exercices/pyspark/`). Claude peut **exécuter** le code pour valider.
- **Fabric** : **fiches + questionnaires** (`exercices/concepts/`), et **hands-on** dès que tu as un compte d'essai.
- **Feuille de route** : `Programme_Fabric_PySpark.md`.

## Mise en place du hands-on Fabric (quand tu veux pratiquer pour de vrai)
- **Compte d'essai Microsoft Fabric** : essai gratuit (≈ 60 jours) sur `app.fabric.microsoft.com` — il faut un compte pro/école (une adresse perso type Gmail ne suffit pas toujours ; sinon créer un tenant Microsoft 365 developer gratuit).
- **Ressources gratuites** : Microsoft Learn — parcours **DP-700** (Fabric Data Engineer) et **DP-600** (Fabric Analytics Engineer) ; doc officielle `learn.microsoft.com/fabric`.
- Dépose toute ressource utile (offre, tuto, doc) dans un dossier `raw/` si besoin.

## Arborescence
- `cours/` : fiches de cours (`01_...`, `02_...`).
- `exercices/pyspark/` : exercices de code PySpark (+ `data/`).
- `exercices/concepts/` : questionnaires / concepts Fabric.
- `fiches-revision/` : révisions + Q&R d'entretien.
