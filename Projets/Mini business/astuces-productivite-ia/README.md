# Astuces productivité / IA / data — format faceless

**Pitch :** vidéos courtes (capture d'écran + voix) montrant une astuce concrète : raccourci Excel/Power BI, prompt IA utile, petite automatisation. Faceless (jamais le visage ni le nom réel), posté en parallèle sur TikTok, YouTube Shorts et Instagram Reels sous le même pseudo.

**Statut :** en test

**Pourquoi ce format plutôt que Reddit stories / podcast clips / citations (voir `Idees_en_attente.md`) :**
- Niche parmi les plus performantes actuellement (productivité, finance perso, outils IA) — RPM (revenu pour 1000 vues) plus élevé : 15-30€/1000 vues contre 0,50-1€ pour les citations.
- Contenu basé sur un vrai savoir-faire (pas du texte Reddit lu par une IA) → risque beaucoup plus faible d'être classé "contenu IA inauthentique" (des milliers de chaînes de ce type ont été démonétisées début 2026).
- Pas besoin de compétence en écriture/scénario poussée : une astuce = une vidéo, format très répétable.

## Checklist des critères du projet
- [x] Peu/pas de coût de départ — outils gratuits listés ci-dessous.
- [x] Anonyme — écran + voix IA/texte, jamais le visage ni le nom.
- [~] Automatisable — pas au début (il faut valider manuellement ce qui marche), mais scriptable ensuite (génération de scripts + sous-titres via des outils/API une fois le format rodé).
- [ ] Rapide — **non**, à ne pas perdre de vue : même optimisé, ce format demande 6-12 mois de publication régulière avant un revenu significatif. Ce n'est pas un business "rapide", c'est un projet de fond à mener en parallèle, sans rien en attendre les premiers mois.

## Outils (gratuits pour démarrer)
- Enregistreur d'écran : OBS Studio (gratuit) ou l'enregistreur natif Windows.
- Montage + sous-titres automatiques : CapCut (gratuit).
- Voix IA : TTS intégré à TikTok/CapCut (gratuit) ou ElevenLabs (offre gratuite limitée).
- Miniatures/visuels : Canva (gratuit).
- Comptes : TikTok + YouTube Shorts + Instagram Reels, même pseudo, création gratuite.

## Plan en 4 phases

### Phase 0 — Setup (semaine 1)
Créer les 3 comptes sous pseudo, bio cohérente, installer/tester les outils, choisir les 3-5 premiers sujets dans `idees_videos.md`.

### Phase 1 — Test, sans attente de revenu (semaines 2-6)
3-5 vidéos/semaine (pas plus, pour rester soutenable). Chaque vidéo : hook fort dans les 3 premières secondes (c'est là que se joue toute la rétention), 1 astuce concrète, CTA simple. Objectif : 60 %+ de temps de visionnage moyen. Aucun objectif d'argent ce mois-ci — on calibre ce qui retient l'attention. Résultats à noter dans `suivi_perf.md`.

### Phase 2 — Ajustement (mois 2-3)
Garder uniquement les sujets/formats qui ont le mieux marché en phase 1, arrêter le reste. Ajouter un lien en bio (ressource gratuite contre un mail, par exemple) pour construire un actif indépendant des plateformes.

### Phase 3 — Monétisation (mois 4-6+)
Une fois les seuils atteints (TikTok : 10k abonnés + 100k vues/30j ; YouTube Shorts : 500 abonnés + 3M vues/90j pour le 1er palier, 1000 + 10M pour la pub complète) : activer les programmes créateurs. Ne pas compter dessus seul — ajouter de l'affiliation sur les outils recommandés (Notion, ChatGPT Plus, etc.) et envisager un petit produit numérique (lien possible avec les templates Power BI mis de côté dans `05 Mini business` historique).

## Automatisation (plus tard, pas maintenant)
Une fois un format validé manuellement : scripter la génération des textes courts et le sous-titrage. Ne pas automatiser avant d'avoir la preuve manuelle que ça marche, sinon on scale l'erreur.
